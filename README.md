# 知识管理系统 - 资料整理

这是一个知识管理系统的前端界面实现，用于管理和查看文档资料。

## 功能特点

- ✅ 文档列表展示
- ✅ 搜索文档功能
- ✅ 上传新文档（UI）
- ✅ 查看和删除文档（UI）
- ✅ 进度条状态显示
- ✅ 分页控件
- ✅ 响应式设计

## 文件结构

```
/workspace/
├── index.html      # 主页面
├── styles.css      # 样式文件
├── package.json    # 项目配置
└── README.md       # 说明文档
```

## 如何使用

### 方法1: 直接打开

直接在浏览器中打开 `index.html` 文件即可查看。

### 方法2: 使用本地服务器

1. 如果安装了 Python 3:
   ```bash
   python -m http.server 8000
   ```

2. 如果安装了 Node.js:
   ```bash
   npx serve .
   ```

3. 然后在浏览器中访问: `http://localhost:8000`

## 主要功能说明

### 1. 左侧导航栏
- 首页导航
- 知识文库管理（当前页面）
- 课程管理

### 2. 文档管理
- 查看文档列表
- 搜索文档名称
- 上传新文档按钮
- 查看/删除操作

### 3. 状态显示
- 绿色进度条显示文档处理状态

### 4. 分页功能
- 上一页/下一页按钮
- 页码直接跳转
- 显示总条数和每页条数

## 自定义修改

### 修改文档数据

在 `index.html` 中找到 `documents` 数组，可以添加或修改文档数据：

```javascript
const documents = [
    { 
        id: 1, 
        name: '文档名称.pdf', 
        status: 100,  // 0-100 的进度值
        knowledgePoints: 27  // 知识点数量，null 表示未处理
    },
    // ... 更多文档
];
```

### 修改样式

编辑 `styles.css` 文件可以自定义：
- 颜色主题（主要颜色 #1890ff）
- 布局尺寸
- 字体样式
- 动画效果

### 添加功能

当前按钮功能为示例代码，可以在 `index.html` 的 `<script>` 部分添加实际的业务逻辑：
- 文件上传处理
- 与后端 API 交互
- 数据持久化
- 用户权限管理
